## O que mudou

- Identidade visual renovada, com navegação responsiva e conteúdo atualizado.
- Três projetos em destaque: [Incident Response Workbench](https://github.com/ArthurCybSec/Incident-Response-Workbench), [SOC Home Lab](https://github.com/ArthurCybSec/SOC-Home-Lab) e [Port-Auditor 2.0](https://github.com/ArthurCybSec/Port-Auditor).

- Layout acessível ao teclado, `prefers-reduced-motion`, descrições de imagens e navegação por âncoras.
- Tema claro/escuro com preferência salva, barra de progresso de leitura, atalhos de navegação e interações discretas sem bibliotecas externas.
- Captura real do Incident Response Workbench com dados sintéticos, ampliável pelo visitante.
- HTML, CSS e JavaScript sem dependências, build, rastreadores ou formulário externo.

## Desenvolvimento local

Abra `index.html` diretamente no navegador. Não é necessário instalar pacotes. GitHub Pages publica os arquivos estáticos da branch `main`.

Estrutura:

```text
index.html          Conteúdo e estrutura semântica
style.css           Estrutura visual e responsividade
enhance.css         Temas, identidade visual e interações de interface
app.js              Menu, tema, navegação ativa e animações leves
workbench-preview.png  Captura da demonstração com dados sintéticos
arthur-soares.jpg   Fotografia do autor
cyber.ico           Ícone do site
```
